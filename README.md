# 幸存者（survivor-game）

吸血鬼幸存者风格的 2D 生存射击小游戏，用 **Cocos Creator 3.8 + TypeScript** 从零开发。

## 🎮 在线试玩

👉 **https://xiao-xiyi.github.io/survivor-game/**

（用电脑浏览器打开，需要键盘才能玩）

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| `J` | 射击（自动朝最近的敌人） |
| `空格` | 开始游戏 |
| `ESC` | 暂停 / 继续 |
| `R` | 死亡后重新开始 |
| `1` `2` `3` | 升级时三选一 |

## 技术点

- TypeScript 面向对象：玩家 / 敌人 / 子弹 / 生成器 / UI 分模块
- 对象池复用子弹、敌人、伤害飘字（避免运行时频繁创建销毁导致的卡顿）
- 游戏状态机：菜单 → 进行中 → 暂停 → 死亡 → 重开
- 难度曲线：生成间隔与敌人血量随存活时间增长，且设有下限护栏
- 数据持久化：最高分用 `sys.localStorage` 存档（Web 和微信小游戏通用 API）
- 伤害飘字、受击特效、音效系统（AudioMgr 单例）
- GitHub Pages 在线部署，一键发布脚本

## 怎么运行

1. 用 Cocos Creator 3.8.x 打开本目录
2. 打开 `scenes` 场景，点预览

## 发布到线上

在 Cocos 里「构建发布 → Web Desktop」之后，双击项目根目录的「**双击部署.bat**」。
